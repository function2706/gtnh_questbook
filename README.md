# GTNH クエストブック 日本語訳ビューア

GregTech: New Horizons (GTNH) のクエストブックを、日本語で読む・疑似的に進めるためのツール一式です。

- 公式の日本語訳（GTNH-Translations / ParaTranz のコミュニティ訳）を使い、未訳の部分は AI（Claude）による翻訳で補っています。AI訳には「AI訳」バッジが付きます。
- ブラウザで開くだけで使え、インターネット接続は不要です（同期するときだけ必要）。
- 作ったゲーム用の翻訳ファイルを、自分の GTNH に入れることもできます。

---

## 1. はじめに

### 必要なもの
| 用途 | 必要なもの |
|---|---|
| ページを見る | Chrome / Edge / Firefox などのブラウザ |
| 同期・ゲームへの反映 | Python 3.8 以降（tkinter 付き。Windows の公式インストーラーなら標準で入っています）と Git |

### ファイルの置き方
次のファイルは **同じフォルダに置いたまま** 開いてください。HTML 単体では表示されません。

```
GTNH_QuestBook_ja.html   … 閲覧ページ
GTNH_QuestProgress.html  … 進行モード（疑似プレイ）
questdata.js             … クエストと翻訳のデータ（両ページ共通）
qb_common.js / qb_common.css … 両ページ共通の処理と見た目
```

## 2. 閲覧ページ（GTNH_QuestBook_ja.html）

ダブルクリックでブラウザが開きます。

### 画面の見方
- **左の章一覧**：章を選ぶと、その章のクエストが並びます。下のバーは翻訳率（橙＝公式訳、青＝AI訳）。
- **クエストのカード**：タイトルをクリックすると本文が開きます。
- **リスト／マップ**：章の右上で切り替えます。マップはゲーム内と同じ配置です。

### ヘッダーの機能
| 機能 | 説明 |
|---|---|
| 検索欄 | 日本語・英語どちらでも検索。スペース区切りで AND 検索。本文中のヒット箇所が抜き出して表示されます |
| 検索範囲 | 「タイトル＋本文」か「タイトルのみ」 |
| 日本語／対訳／English | 本文の表示言語。対訳は日本語と英語を左右に並べます |
| すべて表示 ▾ | 公式訳のみ／AI訳のみ／未訳のみ に絞り込み |
| すべて開く | 表示中のカードをまとめて開閉 |
| 表示項目 ▾ | カード内に出す情報を選択：課題・必要アイテム／報酬／前提・後続クエスト |
| 進行モードへ | 今見ている章・クエストのまま進行モードに切り替え |
| ◐ | ライト／ダークの切り替え |

### カードに出る情報（表示項目でオン／オフ）
- **課題**：アイテム提出（必須／任意、消費あり／なし、いずれか1つ）、クラフト、チェックボックス、討伐、到達、液体提出。課題が複数あるときは「すべて達成」か「いずれか1つで達成」かも表示。
- **報酬**：アイテム、選択式（1つ選ぶ）、経験値、別クエストの完了。
- **前提／後続クエスト**：クリックでそのクエストへ移動。別の章のものには章名が付きます。

> アイテム名は現在 ID 表示です（例：`bamboo  BiomesOPlenty ×64`）。マウスを乗せると完全な ID が見られます。→「7. 既知の制限」

### マップの操作
| 操作 | 内容 |
|---|---|
| ドラッグ | 移動 |
| ホイール／ピンチ | 拡大・縮小 |
| ＋／－／全体 | 拡大・縮小・章全体を表示 |
| 名前 | ノード下のタイトル表示のオン／オフ |
| ノードにマウスを乗せる | タイトル全文を表示 |
| ノードをクリック | 右側（スマホでは下側）に詳細を表示 |

- ノードの色：橙＝公式訳、青＝AI訳、黄＝未訳。中の数字はリストでの番号。
- タイトルは周りと重ならない幅だけ表示し、入らない分は「…」で省略します。拡大すると表示される文字が増えます。
- 線は前提クエストからの矢印です。破線は補助的な前提です。

## 3. 進行モード（GTNH_QuestProgress.html）

ゲームを進めるように、クエストを「クリア」していくと後続が解放されていく疑似プレイです。

### 基本の流れ
1. 最初は前提クエストのないクエストだけが表示されます（初期設定では「最初の夜に向けて」1件）。
2. カードの **「クリア」** を押すと達成扱いになり、条件を満たした後続クエストが **「NEW」** 付きで現れます。
3. 前提が「どれか1つ」の条件のクエストは、そのうち1つをクリアすれば解放されます。

### 画面と機能
| 機能 | 説明 |
|---|---|
| 挑戦可能なクエスト（全章） | 左の一番上。今クリアできるクエストを全章分まとめて表示 |
| 章一覧 | 各章の「挑戦可能」件数とクリア数。まだ何も解放されていない章は薄く表示 |
| リスト／マップ | 章ごとに切り替え。マップはクリア済みが緑の点線＋✓、挑戦可能が橙 |
| この章の挑戦可能をすべてクリア | 序盤の早送りなどに |
| 取り消し | クリアを取り消します。条件を満たさなくなる後続のクリアも連鎖して戻ります（確認あり） |
| クリア済みを表示 | クリア済みクエストを表示するかどうか |
| 特殊クエストを含める | ゲーム内で普段隠れているクエスト（下記）を対象に含めるか。初期設定はオフ |
| 進行データ ▾ | 書き出し（JSON ファイル）／読み込み／最初からやり直す |
| 閲覧モードへ | 今見ている章・クエストのまま閲覧ページに切り替え |

**特殊クエスト**とは、次の 20 件です。
- 可視性が SECRET／HIDDEN のもの（「伝説のクエスト」「ルート・ゲーム」など）
- 前提がブック外の「Trigger」クエスト（アイテム所持などで裏で達成される仕掛け）だけのもの（「隠しクエスト：命がけの取り引き」など）

### 進行状況の保存
- 進行状況はブラウザの中に自動保存されます。同じブラウザで開けば続きから再開できます。
- ブラウザのデータを消すと消えるので、大事な進行状況は「進行データ ▾ → 書き出し」で JSON ファイルに保存しておいてください。別の PC やブラウザへは「読み込み」で移せます。

### 設定の共有
テーマ・言語表示・表示項目・マップの名前表示・リスト／マップの選択は、閲覧ページと進行モードで共通です。片方で変えると、もう片方にも反映されます。

## 4. 同期ツール（sync_gui.pyw）

公式訳やクエスト定義が更新されたときに、最新の内容でページを作り直すためのツールです。`sync_gui.pyw` をダブルクリックすると起動します（コンソール画面は出ません）。

| ボタン | やること |
|---|---|
| まとめて実行 | 下の 1→2→3 を順に実行（普段はこれだけで OK） |
| 1. 公式訳を取得 | GitHub から公式の日本語訳と英語原文を取得。更新があれば旧ファイルを `.bak` に残して差し替え |
| 2. クエスト定義を更新 | マップの配置・前提・課題・報酬のデータを最新化（初回は自動で取得） |
| 3. HTMLを生成 | 閲覧ページ・進行モード・ゲーム用翻訳ファイルを作り直す |
| ゲームに反映… | ゲーム用翻訳ファイルを GTNH に入れる（→「5. ゲームへの反映」） |
| HTMLを開く／フォルダを開く | 生成したページや、このフォルダを開く |

- 画面上部に各ファイルの更新日時、下部に実行ログが出ます。
- 英語原文が更新されて古くなった AI 訳は、自動的に外して「未訳」に戻します（ログに件数が出ます）。新しく未訳が出たときは、その分の翻訳を Claude に依頼してください（→「6. メンテナンス」）。

## 5. ゲームへの反映

公式訳と AI 訳をまとめた翻訳ファイルを、自分の GTNH に入れられます。

1. 同期ツールで「まとめて実行」または「3. HTMLを生成」を実行します。
2. 「ゲームに反映…」を押し、GTNH のインスタンスフォルダ（またはその中の `.minecraft`）を選びます。
3. 次の場所にコピーされます。もともとあったファイルは `ja_JP.lang.bak` として残ります。
   ```
   <.minecraft>\config\txloader\forceload\betterquesting\lang\ja_JP.lang
   ```
4. ゲームの言語を日本語にして起動します（起動中なら再起動）。

- 選んだフォルダは記憶されるので、2 回目以降は確認ダイアログで「はい」を押すだけです。
- 元に戻すときは、`ja_JP.lang` を削除して `ja_JP.lang.bak` を `ja_JP.lang` に名前を戻してください。
- **バージョンに注意**：遊んでいる GTNH と翻訳データのバージョンがずれると、追加・変更されたクエストは英語のまま表示されます。公式訳を取り直したら、もう一度「ゲームに反映…」を押してください。
- ゲーム用ファイルを手で取り出したい場合は `dist\config\txloader\forceload\betterquesting\lang\ja_JP.lang` にあります。

## 6. メンテナンス（翻訳の追加・ファイル構成）

### コマンドラインでの生成
```
python build_questbook_html.py                        # GitHub から最新を取得して生成
python build_questbook_html.py src/ja_JP.lang src/en_US.lang   # 手元のファイルから生成
```

### 未訳が出たときの AI 翻訳の流れ
1. `python split_untranslated.py [分割数]` … 未訳を `work/in/chunkNN.lang` に分割、用語集 `work/glossary.tsv` を作成
   - **注意**：既存の `work/in/chunk*.lang` は消えて作り直されます。AI 訳の「元にした英語」の記録なので、実行前にコミットしておくこと。
2. 各チャンクを翻訳して `work/out/chunkNN_pMM.lang` に保存（Claude に依頼）
3. `python check_translation.py all` … 欠落・書式（%n／タグ／URL など）の崩れを検査
4. `python unify_terms.py` … 《訳／原文》表記の訳語ゆれを最頻の訳に統一
5. `python build_questbook_html.py` … 生成

### ファイル構成
| パス | 内容 |
|---|---|
| `template.html` / `progress_template.html` | 閲覧ページ・進行モードの元（生成時にそのまま出力） |
| `qb_common.js` / `qb_common.css` | 両ページ共通の処理・見た目 |
| `questdata.js` | 生成されるデータ（翻訳・章・配置・課題・報酬） |
| `build_questbook_html.py` | 生成スクリプト |
| `sync_gui.pyw` | 同期ツール |
| `split_untranslated.py` / `check_translation.py` / `unify_terms.py` | 翻訳作業用スクリプト |
| `src/ja_JP.lang` / `src/en_US.lang` | 公式の日本語訳・英語原文 |
| `src/modpack/` | クエスト定義（GT-New-Horizons-Modpack の一部。git 管理外） |
| `src/item_names.tsv` | アイテム名の対応表（`make_item_names.py` で NEI のダンプから生成）。`登録名<TAB>ダメージ値<TAB>表示名` |
| `work/in/` `work/out/` | AI 翻訳の入力（元の英語）と出力 |
| `work/glossary.tsv` | 公式訳から抽出した用語集 |
| `work/patch_*.py` ほか | 開発時に使った一回限りの変更スクリプト（記録用） |
| `dist/` | 生成されるゲーム用翻訳ファイル（git 管理外） |

### 翻訳ファイルの表記について
lang ファイルでは `%n`＝改行、`%%`＝「%」、`\\`＝「\」です。ページ生成時に元の文字に戻しています。GTNH 独自の `&g&#RRGGBB&#RRGGBB`（グラデーション）、`&#RRGGBB`（色）、`&z`（虹色）、`&r`（リセット）も表示に反映しています。

## 7. 既知の制限

- **アイテム名が一部 ID 表示**：クエスト定義には登録名とダメージ値しかないため、名前はゲーム内 NEI のダンプから作った対応表 `src/item_names.tsv` で表示しています。現在はクエストに出てくるアイテムの約 6 割に名前が付き、残り（主に GregTech の機械など）は ID 表示です。
  - 対応表の作り方：ゲーム内で NEI の Options → Tools → Data Dumps を実行し、出力された `dumps` フォルダを指定して
    `python make_item_names.py <dumpsフォルダ>` → `python build_questbook_html.py`
  - 使うのは `itempanel.csv`（最優先）・`oredict.csv`・`item.csv`。**Item Panel のダンプは NEI の検索欄を空にしてから**実行すると全アイテムが出力され、名前の付く割合が上がります。
  - ゲームの言語を日本語にしてダンプすると、アイテム名も日本語になります。
- **アイコンなし**：マップのノードはアイコンではなく四角と番号で表示します。
- **AI 訳の品質**：AI 訳は書式の検査は通していますが、人の目で内容を確認したものではありません。気になる箇所は「対訳」表示で英語原文と見比べてください。
- **ページ上での同期は未対応**：同期は同期ツールで行います。
